# 위석량 | Frontend Portfolio

React와 Next.js를 중심으로 관리자 CMS, 사용자 웹 페이지, 모바일 앱을 개발해 온 프론트엔드 개발자 위석량의 포트폴리오입니다.

기획자, 디자이너, 백엔드 개발자와 요구사항을 구체화하고 사용자와 팀 모두가 이해하기 쉬운 화면과 구조를 만드는 데 집중합니다.

- [포트폴리오 보기](https://achates09.github.io/frontend-portfolio/)
- [GitHub](https://github.com/Achates09/)
- [Email](mailto:srw0901@gmail.com)

## 핵심 역량

- React와 Next.js 기반 관리자 CMS 및 사용자 페이지 개발
- Redux와 Redux-Saga를 활용한 상태 및 비동기 흐름 관리
- 납품처별 요구사항을 공통 템플릿 구조로 정리한 장기 운영 경험
- React Native Expo 기반 모바일 앱 개발 및 배포
- 기획, 디자인, 백엔드 및 프로젝트 관계자와의 협업

## 주요 프로젝트

### SEDN V2 미디어 시스템

- CMS 관리자 페이지와 사용자 페이지 개발 및 유지보수
- 기관별 화면과 운영 요구사항을 CMS 설정 기반 템플릿으로 구조화
- 공공기관과 협회 등 여러 운영 환경에 동일한 솔루션 기반 적용
- 기술: React, Next.js, Redux, Redux-Saga, styled-components
- [서비스 소개](https://sedn.software/) · [데모](https://sedn.software/demo)

### SK Broadband 테스트 자동화 시스템

- 인터넷 모뎀 원격 테스트 및 펌웨어 업데이트 관리자 화면 개발
- SK Planet 백엔드 개발자와 API 명세 및 예외 흐름 조율
- 기술: React, styled-components

### 법원TV STT 기능 연동

- 법원TV 생방송 페이지 UI 및 기능 커스텀 개발
- 방송 페이지 내 Speech to Text 기능 연동
- 기술: JSP, HTML, CSS, JavaScript
- [법원TV](https://tv.scourt.go.kr/)

### Remind 소아·청소년 디지털 멘탈케어 앱

- 아이, 부모, 상담사를 위한 모바일 앱 3종 개발 및 배포
- 헬스 데이터, 푸시 알림, 영상 콘텐츠 및 카카오 로그인 연동
- 서울대학교병원 소아청소년정신과와 협업
- 기술: React Native Expo
- [서비스 소개](https://remind.care/)
